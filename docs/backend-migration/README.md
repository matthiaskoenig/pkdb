# Migration records

The repository now ships one backend in `backend/`. The previous Django backend,
search service, uploader, and deployment scripts have been removed by explicit user
request. Use [installation](../installation.md) and [local upload testing](../local-upload-testing.md)
for current commands.

Files in this directory preserve historical execution, provenance, validation,
performance, and compatibility evidence. References to `backend-next/`, the former
backend, or removed commands describe those historical runs. They are not instructions
for the current checkout.

Source retirement does not mark outstanding scientific corpus or client compatibility
acceptance gates complete. It does not migrate production data or remove existing
operational volumes.
