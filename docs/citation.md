# Citing PK-DB

All outputs using PK-DB data must cite the PK-DB paper and the original publications for the studies used, as required by the [Terms of use](terms-of-use.md). Cite the database paper as follows:

> Grzegorzewski J, Brandhorst J, Green K, Eleftheriadou D, Duport Y, Barthorscht F, Köller A, Ke DYJ, De Angelis S, König M. *PK-DB: pharmacokinetics database for individualized and stratified computational modeling*. Nucleic Acids Res. 2021 Jan 8;49(D1):D1358-D1364. doi: [10.1093/nar/gkaa990](https://doi.org/10.1093/nar/gkaa990). PMID: [33151297](https://pubmed.ncbi.nlm.nih.gov/33151297/).

If you use PK-DB code cite in addition

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.1406979.svg)](https://doi.org/10.5281/zenodo.1406979)

Use of more than 10 studies requires collaboration and coauthorship with Matthias König as described in the [substantial reuse terms](terms-of-use.md#substantial-reuse-and-coauthorship). Commercial use requires a [data license](terms-of-use.md#commercial-use-and-data-licensing). Contact [Matthias König](mailto:koenigmx@hu-berlin.de) to arrange collaboration or licensing.
