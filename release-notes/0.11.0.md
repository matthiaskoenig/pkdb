# Release notes for pkdb 0.11.0

- Publish the public `pkdb` Python package on PyPI, with synchronized client and server versions and support for Python 3.14 on Linux, macOS, and Windows.
- Prepare, validate, and upload existing `pkdb_data` study folders with `pkdb prepare PATH`, `pkdb validate PATH --offline`, and `pkdb upload PATH --endpoint URL`. Preparation and validation reuse the server's scientific processing code and preserve original source files.
- Provide a typed Python client for study queries, authenticated downloads, and uploads using API keys. Bundle reference vocabulary for offline use and support explicit vocabulary synchronization with a content-addressed cache.
- Check server processing and vocabulary compatibility before uploads, validate immutable source snapshots, and retain server-side validation and permission checks.
- Separate the server distribution as `pkdb-server`, with the `pkdb_server` import namespace and `pkdb-server` administration command. Update container builds and deployment instructions for the shared package layout.
- Require authentication for dataset and attachment downloads, remove frontend download actions, and update navigation, branding, footer, and account avatars (#791, #793, #794, #795, and #796).
- Publish the public client through PyPI Trusted Publishing only after the release test suite succeeds. Attach both client and server distributions to the GitHub release.

Install the client with `pip install pkdb==0.11.0` using Python 3.14. Existing server scripts must change their administration command from `pkdb` to `pkdb-server` and server imports from `pkdb` to `pkdb_server`. Container builds now use the repository root as their build context. Publishing this release does not deploy the application.
