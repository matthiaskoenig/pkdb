# Release notes for pkdb 0.11.1

- Simplify the REST API with study and measurement lists, typed advanced queries, consistent pagination, and authenticated dataset exports. The Python client now uses the v2 query and export routes (#822).
- Make MCP strictly read-only: expose study search, canonical study retrieval, and scientific queries; remove validation and replacement tools. Use REST or the Python client for curation.
- Group API documentation by purpose, provide a separate complete reference, and add executable Python and curl examples with tested outputs.
- Remove request throttling for authenticated browser, API-key, and MCP callers. Keep anonymous protection and show readable quota feedback in the frontend.
- Add readable upload progress and structured, versioned backend reports with actionable issue locations, spreadsheet rows, correction hints, and persistence status (#823).
- Improve vocabulary browsing, external annotation links, and negative change measurements. Simplify the landing page and document local uploads, citation requirements, and data-use terms.
- Fix API-key uploads and preserve private-study visibility; improve frontend live reload and release information.

Install the client with `pip install pkdb==0.11.1`. Update the server alongside the client because queries and exports now use v2 routes. Obsolete REST account aliases, underscore CRUD, staged uploads, and JSON-suffix routes are disabled by default; set `PKDB_LEGACY_API_ENABLED=true` temporarily if older integrations still require them. This setting never restores MCP write tools. Browser search compatibility routes remain available.

Client and server distributions use the same release version. Publishing this release does not deploy the application or rebuild existing containers.
