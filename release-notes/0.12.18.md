# Release notes for pkdb 0.12.18

pkdb 0.12.18 corrects the names of two measurement types: `muliple_dosing_cmin` and `muliple_dosing_cmax` become `multiple_dosing_cmin` and `multiple_dosing_cmax`. Their SIDs stay the same, so the database needs no migration; the server applies the new names at startup.

## Changes

- The measurements `muliple_dosing_cmin` and `muliple_dosing_cmax` are renamed to `multiple_dosing_cmin` and `multiple_dosing_cmax` (#1045). Their SIDs stay the same, so the stored measurements take the new names without a database migration. The misspelled names stay as deprecated terms: study folders that use them still validate, with the warning `deprecated_measurement`, until they are renamed. `docs/vocabulary.md` describes how to rename a term.
- Dependencies: the backend locks virtualenv 21.14.13 (#1040) and filelock 4.2.1 (#1041), the frontend undici 8.12.3 (#1039) and follow-redirects 1.16.1 (#1026).
