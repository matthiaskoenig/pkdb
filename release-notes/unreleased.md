# Unreleased

## Changes

- Harden the images and metadata of `pkdb migrate` (#TBD): study names with glob characters such as `[` find their images, JPG images are turned upright by their EXIF orientation and keep their ICC profile as PNG, corrupt PNG images refuse the study as `image_unreadable`, a failed write is reported as `image_write` instead of an unreadable image, malformed curator, comment or description lists and a malformed registry name the study or file and field instead of raising a raw error, and the registry indexes its locations once.

- Follow-ups of `pkdb new` and `pkdb check` (#890). `pkdb new` removes the hidden folder `.NAME.new` that a killed run left, says so, and creates the study, when the folder holds only the unfinished study folder, the study does not exist and nothing in the folder changed for 10 minutes, so that a running `pkdb new` is never disturbed; a younger folder is refused as before. `pkdb check` says that a `PATH` does not exist, prints usage errors as `{"ok": false, "error": "..."}` on stderr with `--format json`, reports an unexpected error of one study as an `unreadable_study` problem and still checks the others, turns an unreadable studies folder into a usage error, leaves an untracked file with a name that is not valid UTF-8 out of `--staged` like other untracked files, and counts every study for the identifier and issue checks when the checkout lies inside another git work tree. The timing tests of the study format accept a larger ratio of CPU times under load, still far below the ratio of quadratic work.
