# Unreleased

- The web interface guide describes the Studies page and the study page with what each reader sees, and the local curation guide notes that the website shows a study with the same views; all screenshots of both guides are rendered again, the website ones with the new `tools/website_docs/run.sh` on the disposable website of the browser tests.
- A paper table of study format 2 needs its image `<study>_<source>.png` or its raw table `<study>_<source>.tsv`: the raw table is the source of data that no image shows, such as unpublished data, raw data provided elsewhere or a supplement that is not available, where before every source but `Text` needed its image (`missing_image`). A figure still needs its image. Rows of such a source have no image in PK-DB, the curation app and the website show the raw table and say that it is the source, and Add table and `pkdb tables add` do not ask for the image. `pkdb migrate` carries a raw table `<study>_<source>.tsv` that a curator put beside a format 1 workbook into the converted folder and converts its paper table without an image; the hidden format 1 tables `.<study>_<sheet>.tsv` are never raw tables.
