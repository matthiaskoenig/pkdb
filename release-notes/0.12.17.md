# Release notes for pkdb 0.12.17

pkdb 0.12.17 is a security release: the backend and its image no longer trust the emSign root CA whose intermediate keys were compromised (GHSA-6q48-6c7w-9gw2, GHSA-hq85-5cpj-mr62). The database needs no migration.

## Changes

- Security: the backend image and its lock no longer trust the emSign root CA whose intermediate keys were compromised (#1029). The backend requires certifi 2026.10.19 or newer and locks it (GHSA-6q48-6c7w-9gw2), the image builds with uv 0.13.4, whose bundled CA store had the same defect (GHSA-hq85-5cpj-mr62), and upgrades the pip 26.2.1 of the python base images, whose vendored certifi is 2026.06.17, to pip 26.2.2. The workflows install uv with setup-uv 10.3.1.
- The frontend builds with vite 8.3.4 (#1027).
